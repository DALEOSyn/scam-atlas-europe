**Scam Atlas: Europe is out: a free browser game about spotting scams**

Travel through ten European cities and deal with the messages people really get: emails, texts, chats, calls, QR codes and shop pages. Trust it, check it, report it or ignore it? Every scenario ends with the warning signs, the check that would have worked, and what to do if you already fell for it. It can happen to anyone.

All brands in the game are made up. The help screens point to national reporting services in ten countries.

Free, with no accounts and no tracking. Progress stays on your device, and the game plays offline once loaded. English only for now. Accessibility has been checked by an internal, automated audit so far; testing with screen readers is still to come.

Play: https://daleosyn.github.io/scam-atlas-europe/
